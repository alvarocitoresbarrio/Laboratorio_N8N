# Configuración en n8n

1. Importar el JSON de `workflows/`.
2. Configurar credenciales de Google Sheets en los nodos.
3. Seleccionar `Pedidos domótica` / `Hoja 1` en los nodos de pedidos.
4. Seleccionar `INVENTARIO_DOMOTICA` / `Hoja 1` en los nodos de inventario.
5. Comprobar encabezados y nombres de productos.
6. Guardar y ejecutar manualmente.

El JSON no contiene credenciales ni acceso a documentos privados. Los parámetros pueden variar según la versión de n8n; revisar cada nodo después de importar.
